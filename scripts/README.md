# Scripts

Optional helpers — **no runtime required** to read the corpus on GitHub.

| Script | Purpose |
|--------|---------|
| [`generate_roadmap.py`](generate_roadmap.py) | First 100 roadmap files (P1–P3) |
| [`generate_full_expansion.py`](generate_full_expansion.py) | Full expansion batch (354+ pages) |
| [`generate_disciplines.py`](generate_disciplines.py) | Phase 7 discipline hubs |
| [`generate_indices.py`](generate_indices.py) | Regenerate awesome lists & stats |
| [`validate-frontmatter.py`](validate-frontmatter.py) | Count types; validate (basic) |

```bash
python3 scripts/generate_indices.py
python3 scripts/validate-frontmatter.py --stats
```
