# E.C.H.O. Framework

**E**motion hook · **C**ore engine · **H**uman control · **O**utcome gap

Use this worksheet before building any Tier S simulation.

## Worksheet

| Element | Question | Example (Petrie Multiplier) |
|---------|----------|----------------------------|
| **Hook** | One sentence that creates stakes? | Equal meanness. Unequal harm. |
| **Engine** | What system runs? | Random pairwise harassment at equal rate |
| **Control** | What does the user adjust? | Minority share, harassment rate, N agents |
| **Outcome gap** | What did they predict vs what happened? | Fair rates → unfair totals |

## Anti-patterns

- Lecture then quiz
- Reveal without prediction
- Sliders with no named meaning
