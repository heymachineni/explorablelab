# Representativeness × Default (126)

## Definition

Representativeness × Default (126) is a compact cognitive tool for deciding under uncertainty. It is not a law of nature—it is a **lens** that highlights some variables and hides others.

## When to use

- Facing a complex decision where representativeness × default (126) clarifies trade-offs
- Communicating strategy to a team without full formal model
- Sanity-checking an expert's recommendation

## When it fails

- Domain shifts (model trained on wrong reference class)
- Adversarial environments that exploit the heuristic
- High-stakes tail risks where averages mislead
