# S Curve Diffusion × Skin the Game (54)

## Definition

S Curve Diffusion × Skin the Game (54) is a compact cognitive tool for deciding under uncertainty. It is not a law of nature—it is a **lens** that highlights some variables and hides others.

## When to use

- Facing a complex decision where s curve diffusion × skin the game (54) clarifies trade-offs
- Communicating strategy to a team without full formal model
- Sanity-checking an expert's recommendation

## When it fails

- High-stakes tail risks where averages mislead
